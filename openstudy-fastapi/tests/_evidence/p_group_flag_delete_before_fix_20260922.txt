→ **整张 question_* 关系网一条级联都没有**。而 `question_manage._purge_questions`
  只显式删了 `question_sub` / `note_question`，漏了 `user_question_{error,favorite,marked}`。
  这条路径在本轮之前**走不到**（没有任何工具能造出「已被标记的题」）；
  `question_flag_manage`（本轮 #4）上线后，「先收藏/加入错题本，再让助手删掉这道题」
  就是一步普通操作 —— 用户会拿到一句 `工具执行异常：IntegrityError…`，并且题删不掉。

--- 探针步骤（可复现）---
1. execute bank_manage.create        → 自建题库（名字带 __e2e_agent__PROBE_Q）
2. execute question_manage.create    → 自建一道题
3. execute question_flag_manage add(flag_type=favorite, question_id=…) → 入库 +1
4. execute question_manage.delete(question_id=…)  → 期望 success=True
5. 回读 question_main 该行是否还在
（探针在 finally 里按登记的精确 id 物理删：favorite 行 → 题 → 库）
