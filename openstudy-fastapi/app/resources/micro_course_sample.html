核心概念

什么是智能体

  • 智能体不是“会聊天的模型”
  • 它能感知环境、围绕目标做出决策
  • 它会调用工具采取行动，并根据反馈调整下一步
  • 一句话理解：感知 + 决策 + 行动 + 反馈
强调“一句话理解”，请学生跟读一遍，记住四个词。

关键特征

智能体的四个关键特征

  • 目标驱动：围绕一个目标持续推进任务
  • 环境感知：读取文字、表格、网页或系统状态
  • 工具行动：调用搜索、数据库、代码执行器、业务 API
  • 反馈修正：观察结果，判断是否完成，必要时改计划
可以让学生任选一个特征，说一个身边的例子。

核心能力

四个核心能力对照看

  • 感知、规划、行动、记忆各有分工
  • 只生成文字不等于智能体
能力说明典型例子
感知理解当前输入与环境状态读取用户需求、检索资料
规划把目标拆成可执行步骤先查资料，再列提纲，最后生成课件
行动调用工具执行具体操作搜索、计算、发邮件、写文件
记忆保存上下文和历史结果记住用户偏好、上次做到哪一步
提醒：没有目标、行动和反馈闭环，通常只是对话模型。

任务流程

智能体怎样完成任务

  • 理解目标：确认真正想要的结果和约束
  • 制定计划：拆成多个可验证的小步骤
  • 调用工具：按每步需要选择搜索、代码或业务工具
  • 观察结果并调整计划：失败时重试、换工具或澄清
  • 交付结果：文档、课件、表格或可执行的下一步
可以让学生把“写一份课件”按这六步复述一遍。

对比辨析

智能体和普通程序差在哪

  • 执行方式与输入范围不同
  • 失败处理与输出形态不同
  • 关键风险也不同
维度普通程序智能体
执行方式固定规则与流程根据环境反馈动态规划
输入范围结构化参数为主文本、文件、网页、系统状态
失败处理报错或终止重试、换策略、请求澄清
输出确定结果行动、文件或多步结果
关键风险逻辑错误幻觉、越权、工具误用
易错点：智能体不是“更聪明的程序”，风险类型也变了。

评测与安全

评测智能体看什么

  • 不能只看“回答像不像”，要看任务是否真正完成
  • 安全边界关注是否越权读取、修改或外发数据
  • 成本与延迟也要计入完成任务的代价

安全原则

用智能体的四条安全底线

  • 最小权限：只给完成任务必需的权限
  • 敏感操作二次确认
  • 工具调用可审计
  • 失败时明确告知用户
