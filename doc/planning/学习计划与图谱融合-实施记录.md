## 3. 2026-11-08 第二次反馈修正

根据「学习计划页去掉、建议功能搬进知识图谱、不要第二个图谱视图」的反馈：

- 学习统计页删除 `plan` tab 和 `StudyPlanWorkbench`；旧 `?tab=plan` 重定向到 `我的资料 → 知识图谱`。
- 删除旧 `StudyPlanPanel.vue` / `StudyMapGraph.vue` / `StudyPlanWorkbench.vue`；知识图谱页不再新增 ECharts 图谱视图。
- 删除「查看今日学习路径」按钮、详情页「从这一页规划学习路径」入口和图谱上的旧 path 覆盖层；删除「学习雷达」。
- 学习建议抽屉改为与知识百科详情一致的 `ResizableDrawer`（非模态、可穿透），抽屉打开时仍可缩放/拖拽知识图谱；等待文案改为「OpenStudy 正在思考…」。
- 知识图谱滚轮缩放性能优化：滚轮事件只直接更新 SVG `transform`，合并到 rAF 执行，停止期间不触发节点/边 Vue 重渲染；约 140ms 后才提交 `mapView` 状态，并停止初始力导向动画，避免刷新后快速缩放卡顿。
- 知识图谱浮层面板新增「学习建议模式」开关；开启后仍是原来的 SVG 知识图谱视图，不替换视图层。
- 建议模式点击节点只选中节点并打开建议抽屉询问「是否生成建议」，不会打开知识百科详情抽屉。
- 点击「以此生成建议」后抽屉先关闭，沿现有图谱节点播放建议轨迹；轨迹展示完成后抽屉自动打开，并显示生成中的骨架/完整建议。
- 选中节点后隐藏原图谱连线，只保留选中节点高亮；建议轨迹线单独显示并保留上一步射线。
- `study_map_service` 不再把题库题干作为图节点；新增 `source_entity_service.py` 从题库正文/解析抽取知识点、实体与关系（供建议侧使用，不把题目原文塞进图谱）。
- 为演示资料夹补了 3 条图片资产，演示图谱来源覆盖题库、文档、网站、图片。

### 2026-11-08 连线与射线修正

- `study_advice_service` 的边优先级改为 `prerequisite → mention → related → ... → source_doc`，避免从主题页先跳到资料文档导致「微分」等节点看不到真实主题连线。
- 实测「微分」seed 轨迹：微分 → 导数 → 微分中值定理 → 求导法则 → 罗尔定理 → 函数 → 连续，共 6 步。
- 建议射线按步逐条显示（约每 560ms 一条），每条线从起点向终点绘制，已出现射线保留；不再一次性全部出现。
- 每条射线同一时刻只有一个亮点，亮点跑完整条线后才消失，下一条线才出现新亮点；亮点速度较最初版本降低约 30%（约 1.5 秒/条）。
- 轨迹经过的每个节点都显示标题，字体/颜色与起点节点一致，不再被整体灰化；节点不是看到射线就亮，而是亮点真正跑到该节点后才点亮（实测 1.2 秒仅起点 1 个节点、2.8 秒 2 个、5.8 秒 4 个、9.8 秒 7 个）。
- 学习建议抽屉内容区改为可滚动高度适配，长建议不会再被底部截断。
- 建议面板导出菜单明确为「导出图片（PNG）」「导出文本（TXT）」「导出 PDF」；PDF 由后端 `/rag/study-plan/advice/export` 生成，图片由前端 `html2canvas` 生成。
- 学习建议模式支持取消选中：再次点击已选中的同一节点，会清除高亮、恢复图谱连线并关闭建议抽屉，不需要退出建议模式。
- 历史记录切换修复：读取历史快照时先清空旧轨迹，再按 `scope.seedNodeId` 把视角移动到历史起点节点，并重新播放该版本的连线动画；实测从 B 节点切到历史 C 节点时，选中态从 B 切到 C。
- 学习建议术语精简：生成和历史快照展示都去掉 `topic:/doc:/bank:`、`degree/viewCount/practiceCount/mappedQuestionCount`、`mention/prerequisite/part_of` 等内部字段，改成「关联较少 / 暂无阅读 / 暂无练习 / 题目暂未对应 / 主题关系 / 前置关系」等中文短语；LLM 提示词限制风险条目 35 字以内。
- 用户可见名称统一为「规划建议」/「规划建议模式」，覆盖知识图谱浮层、建议面板、聊天生成式卡片、导出文件、Agent 工具标签和后端错误提示；不再把比赛信息、资料分析等内容统称为「学习建议」。
- LLM 提示词增加内容类型判断和少量 few-shot 示例：比赛通知（报名条件/材料/演练/提交）、资料分析（结论/口径/数据/行动）；提示词要求标题和阶段贴合用户语境，只有学习材料才使用知识点/练习表述。
- 资料夹上传菜单新增「从题库导入」：`question_bank_kb_link` 只建立资料夹 ↔ 题库逻辑引用，不复制题目；支持查询、关联、取消关联，并在资料夹顶部显示已关联题库。
- `study_map_service` 在未显式传 `bank_ids` 时自动读取当前资料夹的关联题库，让题库参与图谱/规划建议。
- 补齐 `OsIcon` 的 `globe` 图标，网页导入和题库导入入口都有明确图标。新增截图：`148-upload-menu-bank.png`、`149-bank-import-dialog.png`。
- 「更新知识百科」改为下拉式增量更新：默认跳过已 ready 页面；支持只更新一个文档/图片/题库/网页，新增 `/rag/wiki/build/selective`；按来源更新会先标记相关页面 stale，再复用现有构建任务。
- 资料夹中的已关联题库显示完整信息卡片（题库标签、科目、题量、描述、知识点入口、取消关联）。
- 题库关联后后台触发知识点抽取；`source_entity_service.extract_bank_entities` 支持按 20 题一块处理大题库（最多 200 题），最多 3 块并行，再合并实体/关系，避免一次塞满模型上下文。
- 题库抽取增加“总结”后处理：按跨题块命中次数和关系度排序，最多保留 24 个核心知识点、60 条关系，并生成「题库主要聚焦：…」摘要，不再把 100 多道题抽成 100 多个实体。
- 知识百科题库知识点入口展示题库摘要、知识点、关系和题目样例；资料夹题库卡片提供「查看知识点」。
- 后端启动时回收上次进程遗留的 `rag_image_describe_job` / `rag_wiki_build_job` 的 `running` 状态，标记为 failed；画廊和知识百科轮询连续 3 次失败也会停止并显示「连接中断」，避免后端重启后前端一直卡在「正在生成描述/更新中」。
