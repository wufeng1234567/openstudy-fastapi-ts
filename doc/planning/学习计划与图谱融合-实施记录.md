# 学习计划 × 知识图谱融合 · 实施记录

> 日期：2026-11-08  
> 对应方案：`doc/planning/学习计划与图谱融合-改造方案.md`  
> 范围：`openstudy-fastapi` + `openstudy-vue3-ts`

## 1. 已完成

### 1.1 后端

- 新增 `app/services/rag/study_map_service.py`：统一 `topic / bank / document / web / note / image` 六类节点与真实边；修复旧 `study_graph_service` 的 `page:{id}` 与裸 page id 命名不一致问题（新图统一 `topic:{id}`）。
- 新增 `app/services/study_advice_service.py`：真实图遍历 `trace` + 事实锁定 + LLM 建议 + 模板降级；`StudyAdvice` 不含 tasks/days/status/progress。
- 新增 `app/services/study_plan_history_service.py` + `app/models/study_plan.py`：`study_plan_snapshot` 快照表，生成自动保存、50 条保留、置顶/重命名/软删除/查看后继续。
- 新增 `app/api/v1/study_plan.py`：`/rag/study-map`、`/rag/study-plan/trace`、`/rag/study-plan/advice`、`/rag/study-plan/history` CRUD。
- 新增 `app/services/document_smart_report_service.py` + `app/api/v1/document_clinic.py`：资料智能报告，输出更新目标、优势、改进项、下一步；不排任务。
- `study_plan` 工具新增 `advise` action，返回 `advice/trace/graph/snapshotId/jumpUrl`；旧 action 保留。
- `prompts.py` 更新资料诊疗室三页文案、`study_plan.advise` 建议语气。

### 1.2 前端

- 新增 `StudyPlanWorkbench.vue`：唯一「学习计划」工作台（条件条 + 图谱 + 建议 + 最近规划）。
- 新增 `StudyGraphCanvas.vue`：ECharts 六类节点、真实边、全屏模式、真实 `trace` 动画（reading/traversing/thinking/ready）、未访问节点暗淡。
- 新增 `StudyAdvicePanel.vue`：建议标题/摘要/阶段/依据/替代方案/风险/快捷调整；无 checkbox、无任务。
- 新增 `StudyPlanHistoryDrawer.vue`：历史列表、搜索、重命名、置顶、删除、查看后继续。
- 新增 `StudyPlanGenerativeCard`：对话页/悬浮助手生成式卡片，复用同一图谱组件。
- `myStats/index.vue` 的 `plan` tab 从旧 `StudyPlanPanel` 切到 `StudyPlanWorkbench`。
- `LearningLoopPanel.vue` 删除「今日学习任务」块与开始按钮，只保留统计。
- `KnowledgeRoutePanel.vue` 降级为「打开学习计划」小卡，不再显示站点/任务。
- `DocumentClinicDialog.vue` 第三页从「学习处方」改为「智能报告」；新增 `DocumentSmartReportPanel.vue`。
- `DocumentAnatomyPanel.vue` 新增「全屏阅读」按钮与 fixed fallback；`workspace/index.vue` 文档行点击直接打开原文阅读。
