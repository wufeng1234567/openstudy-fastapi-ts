## 1. 已完成

### 1.1 图片节点资产化

- 文档内图片（`RagImageAsset.doc_id > 0`）**不再作为独立图片节点进入图谱**；它们仍进入画廊，并用于提取图片级知识点；
- 只有独立图片（`doc_id=null`）才作为 `image` 节点进入图片实体集；
- 独立图片节点 `ref.assetKey` 指向真实图片资产；
- 图片没有知识点时保留独立图片节点，不伪造 `image → topic` 边；
- 图片详情返回 displayName、caption、OCR、keywords、imageKind、descriptionStatus；
- 单独上传图片通过 `/rag/document/upload` 自动创建 `RagImageAsset`（`source_type=upload`，`doc_id=null`），不创建文档；
- 上传后后台自动生成 `displayName` 短名称和 `caption` 描述，并抽取图片知识点；
- 知识百科「按来源更新」下拉现在能识别独立图片资产（`assetId`）；
- 点击任意主题/题库/资料/网页/笔记/图片节点后，规划建议抽屉立即进入「生成中」，不再先显示历史记录；
- 规划建议支持以 `topic:` / `bank:` / `doc:` / `web:` / `note:` / `image:` 节点作为 seed；
- 知识图谱首屏默认不渲染关系线，只有悬停/选中节点时才显示该节点的相邻关系，避免 100+ 节点资料夹初始加载几百条 SVG 线导致卡顿。

### 1.2 图片命名

- LLM 图片描述优先作为图片节点标题；
- 无 caption 时使用 `文档文件名-图N`；
- 独立图片无描述时使用图片文件名；
- 测试图片实际显示为“一张关于智能体基本概念的文档…”，并有真实 OCR 文本。

### 1.3 文档/图片/知识点三元关系

新增边方向约定：

```text
文档 --包含图片--> 图片
图片 --图片知识点--> 知识主题
知识主题 --文档知识点--> 文档
```

- 同一知识点可同时来自文档和图片：主题页 `generation_meta.sources` 保留两条来源；
- 图片多个知识点：一个图片节点连向多个 topic；
- 图片无知识点：只保留文档→图片边；
- 文档多个图片：文档连向多个 image 节点；
- 独立图片：没有 document 边，直接连 topic。

### 1.4 图片来源处理

- `source_graph_state_service` 允许有 caption/OCR 的文档图片进入来源队列；
- `source_graph_service.sync_text_source` 从图片描述/OCR 生成主题页，并写入 `generation_meta.sourceType=image`；
- `study_map_service` 同时识别：
  - `generation_meta.sourceType=image`；
  - `ContentReference` 中 `document_image/chat_image → wiki_page` 的引用；
- 两种路径都生成 `image → topic` 边。

### 1.5 响应式画布

- 画布使用实际容器尺寸计算 viewBox；
- `mapLayoutScale` 按 `width/1200 × height/760` 自适应，最大 1.8；
- 主题节点间距、来源组半径、节点半径、实体集轮廓 padding 跟随布局缩放；
- `fitMapView` 在大屏允许更大适配缩放（最大 2.2），不会让内容缩成一小块；
- 图片多于 6 张时，图片组内部使用网格而非圆周布局；
- 图片超过 8 张时首屏折叠为「图片资产（N）」聚合节点，点击展开，避免几十个红点重叠；
- 标签字号按 `mapView.scale` 反算，并用屏幕坐标碰撞检测避免重叠。

### 1.6 连线可视化

- 右侧「关系说明」显示：
  - 文档 → 图片 · 包含图片
  - 图片 → 知识主题 · 图片知识点
  - 知识主题 → 资料 · 文档知识点
  - 知识主题 → 题库 · 题源关系
- 边 hover 使用原生 SVG `<title>` 显示「关系：源 → 目标」；
- 文档→图片蓝色实线、图片→知识点红色虚线、跨来源虚线高亮。
