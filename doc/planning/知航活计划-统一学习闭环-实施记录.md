# 知航 · 活计划：统一学习闭环实施记录

日期：2026-11-08

## 一句话

**同一条知识图谱航线，按一个目标实时展开成按天任务，做完自动点亮，永不需手动勾选。**

它把「知航学习航线」「学习处方」「学习统计的今日处方」「考前计划」统一成同一个计划对象：
旧功能不删除，作为同一事实源/同一视图的历史入口；新入口是 `知航 · 活计划`。

## 为什么不是“再做一个计划表”

- 不新增 `study_plan` / `plan_task` / `plan_progress` 表；
- 计划是请求期对象，`generatedAt` 每次实时生成；
- 唯一可信事实源：`study_diagnosis_service.diagnose()` + `user_practice_log` +
  `question_source` + `rag_wiki_page_learning`；
- 任务没有真实 `pageId / bankId / questionIds` 就不排，不造假；
- 完成判定只看“计划生成后（`sinceMs`）真实发生过作答/阅读”，不看前端勾选。

## 后端

- 新增 `app/services/study_plan_service.py`
  - `build_study_plan(db, user_id, kb_id, goal, exam_date, horizon_days, daily_minutes, rest_days, focus_page_id, doc_id, section_indexes, mode, since_ms)`
  - `plan_dates()` / `_tasks_for_stop()` / `_pack_days()` / `_apply_progress()`
  - 任务类型：`read / section / practice / question / review / retest / mock`
  - `progress`、`route.stops[].status`、`generatedAt`、`planVersion` 全部实时推导
  - 考前模式额外支持“题库轴”：没有 `QuestionSource` 页面锚点的错题按真实 `bankId` 变成
    `question` 任务，并在 `degraded` 中显式说明，不静默消失。
- 新增 `GET /rag/study-plan`（`app/api/v1/rag.py`）
  - 参数：`kbId, goal, examDate, horizonDays, dailyMinutes, restDays, focusPageId, docId,
    sectionIndexes, mode, sinceMs`
- 新增 Agent 工具 `app/services/ai/agent/tools/study_plan.py`
  - actions：`plan / today / adjust / reassess`
  - 在 `tools/__init__.py` 注册，加入 `roles.py` 的 `GLOBAL_TOOLS`
  - `today` 只返回今日任务和摘要，避免整份计划灌进对话上下文。

## 前端

- 新增 `openstudy-vue3-ts/src/views/front/workspace/components/StudyPlanDrawer.vue`
  - 统一视图：站点航线 + 按天任务 + 真实进度 + 一个主操作「开始今日任务」+ 一个「调整」
  - 无前端完成勾选；答题/阅读后重新拉取即自动推进。
- `KnowledgeWikiPanel.vue`
  - `生成学习计划` 调 `getStudyPlan()`，失败时兼容旧 `getLearningRoute()`
  - 右侧 `KnowledgeRoutePanel` 增加「今日任务 0/3 · 查看完整计划」
  - 计划快照/`sinceMs` 存 `openstudy.workspace.studyPlanState`，只作可重建状态，不存勾选完成态
- `LearningLoopPanel.vue`
  - 学习统计里的「今日学习处方」改读同一份 `GET /rag/study-plan`
  - 有活计划时显示「今日学习任务」，无计划时才显示旧的逐题处方。
- `KnowledgeRoutePanel.vue`
  - 品牌统一为「知航 · 活计划」，保留原航线交互与策略切换。

## 保留 / 不删除

`StudyPrescriptionPanel`、`ExamPlanPanel`、`WeeklyReportPanel`、`DiagnosisPanel` 等旧入口
本轮**不删除**，避免破坏导出、历史 localStorage、专属刷题题库等现有功能。它们可在后续迁移
为同一 `StudyPlan` 的视图，但不在本轮做破坏性收编。
