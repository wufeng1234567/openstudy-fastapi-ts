# 学习计划统一 · 实施记录

日期：2026-11-08

## 一句话

把「知航 · 活计划 / 考前计划 / 今日处方」收口成**一个「学习计划」tab**：知识图谱 + 用户题库在统计页内合成一张可操作地图，任务来自同一份 `build_study_plan`，完成状态只认真实答题/阅读流水；LLM 通过 `study_graph` 查图谱/题库，通过 `study_plan` 读同一份计划。

## 相对初版方案的收敛

审查代理判定原 747 行方案「过于复杂、会造成事实第二入口」，Lead 复审后执行范围收敛：

- 不新增 `GET /rag/study-context`：资料夹直接用现有知识库列表，题库从 `study-graph.banks` 取。
- 不新增 `PlanTaskList` / `study_plan.explain/include_graph`：LLM 用 `study_graph.overview` + `study_plan` 组合即可。
- workspace 不再挂载完整计划抽屉：只保留轻量学习路径预览，完整计划统一在统计页。
- `?tab=exam` 只到隐藏的「历史计划（旧版）」只读归档，不进导航；`ExamPlanPanel` 加 `readonly`，禁止重新生成/复制题库/手动勾选完成。
- `studyPlanState` 键名保持 `openstudy.workspace.studyPlanState`，只做加性字段扩展；不建立第二套计划状态。

## 后端

- 新增 `app/services/rag/study_graph_service.py`
  - page 节点来自 `RagWikiPage` / `get_wiki_graph`
  - bank 节点来自 `question_bank` / `question_main` / `user_practice_log`
  - `bank-page` 边只来自真实 `QuestionSource` 的 doc/chunk 锚点；无锚点不画
  - `weakQuestions` 与计划题库轴共用同一诊断口径
- 修改 `app/services/study_plan_service.py`
  - `build_study_plan(..., bank_ids=...)`
  - `kb_id=0` 时跳过知识页航线，进入 `bank-only`
  - 题库轴任务使用原始 `questionId`，不复制题库、不调用 `_create_plan_bank`
  - 返回 `bankIds / axisSummary / sourceNodeId / bank-only degraded`
- 新增 `GET /rag/study-graph`、`GET /rag/study-plan` 支持 `kbId=0` + `bankIds`
- `GET /userStats/study-plan-today` 改为单次 build 的兼容薄封装，透传 `sinceMs/bankIds`，不再用 `days[0]` 冒充今天
- 修复 `_wiki_practice_bank` 可见性判断反向问题（自己的/公开题库可练）
- 修复 `_wiki_learning_map` 未过滤已物理删除题目的幽灵练习

## 诚实边界

- `QuestionMain` 没有知识点字段；题库只能通过 `QuestionSource` 的 doc/chunk 锚点反查知识页，**没有锚点就 pageId=0**，不按题干猜知识点。
- 当前演示资料夹的题库没有反查到知识页锚点，所以图谱里题库节点独立展示；这是真实数据边界，不是渲染 bug。
- 旧的 `考前计划·` 题库与 `os_exam_plan_v1_*` 快照不删、不改名、不迁移；只退出主流程。
