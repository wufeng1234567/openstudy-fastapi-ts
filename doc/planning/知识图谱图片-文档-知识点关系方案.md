# 知识图谱图片、文档、知识点关系方案

- 日期：2026-11-10
- 状态：已实施（代码完成，待用户审核）
- 关联：`doc/planning/知识图谱统一-六类实体集-方案.md`、`doc/planning/知识图谱统一-实施记录.md`

## 1. 目标

知识图谱需要同时表达三类真实对象：

1. **文档**：一份资料，可以包含文字知识点，也可以包含多张图片；
2. **图片**：一张真实图片资产，可以属于某份文档，也可以独立存在；
3. **知识主题**：从文档正文或图片内容中提取出的知识点。

图片不能被简化成「N 张图」；图片与知识点、文档与知识点必须能看出方向和来源。

## 2. 关系矩阵

| 场景 | 关系 | 方向 |
|---|---|---|
| 文档包含图片 | 文档 → 图片 | 文档为父，图片为子 |
| 图片提取出知识点 | 图片 → 知识主题 | 图片是证据源 |
| 文档正文提取出知识点 | 知识主题 → 文档 | 主题追溯到文档来源 |
| 同一知识点同时来自文档和图片 | 文档 → 知识主题 + 图片 → 知识主题 | 两条来源链都保留 |
| 图片没有知识点，只是辅助说明 | 文档 → 图片 | 图片仍保留，不伪造主题边 |
| 独立图片没有文档 | 图片（无文档边） | 可单独存在 |
| 独立图片有知识点 | 图片 → 知识主题 | 不连到任何文档 |
| 一个图片包含多个知识点 | 图片 → 多个知识主题 | 一对多 |
| 一个知识点来自多张图片 | 多张图片 → 同一知识主题 | 多对一 |
| 一个文档多张图片 | 多个文档 → 图片边 | 一对多 |

### 2.1 边界规则

- 文档内部图片只进入画廊索引和图片级知识点抽取，**不成为 image 图谱节点**；
- 只有 `doc_id=null` 的独立图片才作为 image 节点；
- 没有图片描述/OCR 的图片不生成图片知识点；只保留图片节点。
- 没有知识点的图片不删除；它是辅助说明资产。
- 图片文档关系以 `RagImageAsset.doc_id` 为准；独立图片 `doc_id=null`。
- 同一知识主题可以同时有 `document` 和 `image` 来源，`generation_meta.sources` 保留全部来源。
- 图片详情必须能回到资产（assetKey），文档详情必须能回到原文档。

## 3. 图片命名

优先级：

1. 图片描述任务产生的 LLM `caption`；
2. LLM `ocrText` / `keywords`（当 caption 为空）；
3. 文档图片兜底：`{文档文件名}-图{N}`；
4. 独立图片兜底：`{图片文件名}`；
5. 最后兜底：`图片 {assetId}`。

副标题用于显示来源：

- 文档图片：`{文档文件名} · 图{N}`
- 独立图片：`独立图片`

## 4. 图片知识点命名与描述

图片页面的标题来自 LLM 对图片内容抽取出的实体/概念，不使用「图1/图2」作为主题名。

图片详情显示：

- `caption`：这张图是什么、表达什么；
- `ocrText`：图片内文字；
- `keywords`：图片关键词；
- `assetKey`：可回到画廊图片；
- `document`：所属文档（如果有）；
- `knowledgePageIds`：由这张图提取出的知识主题。

## 5. 布局与分辨率

- 画布尺寸来自容器实际宽高，不写死 1000×640；
- `mapLayoutScale = clamp(min(width/1200, height/760), 1, 1.8)`；
- 主题节点网格间距、节点半径、来源组半径、实体集轮廓 padding 全部乘 `mapLayoutScale`；
- 宽屏 1920/2560/3440 下使用更大的主题间距和来源分组间距；
- 图片节点多时，默认折叠为一个「图片资产（N）」聚合节点，点击后再展开图片组内部网格，避免首屏几十个红点互相挤压；
- 标签字号按缩放反算，碰撞避让只显示不重叠标签。

## 6. 测试资料

生成 `doc/test-data/OpenStudy-智能体图文知识测试.docx`，内容包含：

- 3.1 智能体基本概念（文档级知识点）；

- 3.3 文档与图片混合知识点；
- 3.4 关系说明。

测试目标：

1. 文档节点存在；
2. 文档 → 图片边存在；
3. 图片 → 知识主题边存在；
4. 文档 → 知识主题边存在；
5. 图片节点标题为图片内容描述，不是“N 张图”；
6. 独立图片/无知识点图片仍有节点。

## 7. 实施批次

1. 后端：图片资产节点化、图片命名、图片→知识点边；
2. 后端：文档图片进入来源处理队列，图片页 generation_meta 保留来源；
3. 前端：图片节点渲染、边缘关系说明、图片点击；
4. 前端：响应式布局、主题/来源/图片网格间距；
5. 测试文档生成、上传、图片描述、增量建图；
6. 回归测试、浏览器大屏/普通屏截图、文档更新。
