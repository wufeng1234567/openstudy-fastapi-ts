# 知识图谱统一与六类实体集整合 - 实施记录

- 日期：2026-11-10
- 对应方案：`doc/planning/知识图谱统一-六类实体集-方案.md`
- 状态：代码实施完成，待用户审核

## 1. 已完成

### 1.1 删除独立六类图

- 删除 `KnowledgeWikiPanel.vue` 工具栏「六类图」入口；
- 删除 `switchStudyMap()`、`view === 'study'` 分支和 `STUDY_TYPE_META` 旧视图逻辑；
- 删除 `openstudy-vue3-ts/doc/screenshots/111-six-type-graph.png`。

### 1.2 知识图谱改为统一六类图

- 主画布数据源从 `getWikiGraph`（page-only）切换为 `getStudyMap`；
- 请求 `sourceTypes=wiki,bank,document,web,note,image`，使用后端返回的 `groups` 六类实体集；
- 右侧图例显示六类：知识主题 / 题库 / 资料 / 网页 / 笔记 / 图片；
- 主题节点和来源节点按 kind 着色，来源节点可点击进入资料、题库、笔记或画廊。

### 1.3 合并与来源保留

- 新增 `wiki_merge_service.py`：
  - `source_refs` 并集；
  - `source_doc_ids` 并集；
  - `source_chunk_ids` 并集；
  - `sections` 按来源追加，不覆盖旧来源；
  - `generation_meta.sources` 记录全部来源；
  - 页面 `content_md` 根据合并后的 summary + sections 重算。
- `wiki_service.build_wiki_pages()` 改用合并更新，并用合并后的 `page.sections` 重建 Wiki chunk，避免第二份文档覆盖第一份来源；
- `source_graph_service._sync_entities()` 也改用同一合并逻辑；
- `knowledge_graph_service.merge_duplicate_entities()` 支持同名/别名实体合并（同类型保护），并把页面 `entity_ids` 从旧实体迁移到 keeper 实体。

### 1.4 笔记导入

- 资料夹上传菜单新增「导入笔记」；
- 新增 `NoteImportDialog.vue`：
  - 从我的笔记导入（列出、搜索、选择、关联）；
  - 新建/上传 `.md` / `.txt` 笔记并关联；
- 资料夹显示「已关联笔记」区块，可取消关联；
- `study_map_service` 现在同时读取 `ContentReference` 和 `note_kb_link`，笔记即使暂时没有主题页也会作为来源节点出现；
- `/rag/wiki/build/selective` 支持 `sourceType=note`；
- `note_kb_link_service` 增加笔记标题读取，图谱来源标签显示真实标题。

### 1.5 搜索与筛选

- 知识百科视图打开 `SearchFilterInput` 的筛选入口；
- 筛选组：
  - 实体集类型（知识主题 / 题库 / 资料 / 网页 / 笔记 / 图片）；
  - 主题页类型（摘要 / 实体 / 概念 / 综合 / 对比 / 总览）；
  - 学习状态（未学 / 已读 / 练习中 / 已掌握）；
- 搜索框搜索主题、来源节点标题、摘要、别名，搜索下拉展示节点类型；
- 知识图谱右侧增加「适配视图」操作。

### 1.6 画布边界修复

- 删除固定 `viewBox="0 0 1000 640"`；
- 使用 `ResizeObserver/窗口 resize` 同步实际容器尺寸，动态设置 viewBox；
- 移除节点拖拽的 `30~970 / 30~610` 硬 clamp；
- 节点拖到画布外时自动扩展 world size；
- 实体集轮廓从凸包直线改为平滑径向 blob，并随节点位置重新计算；
- 右侧实体集面板预留约 230px 布局安全区，避免来源组被面板遮挡；
- 主题节点使用中央网格布局，来源组围绕其排列；
- 主题节点网格间距扩大到 `52×48`，节点半径收敛到 5–14px，连线提高可见度；
- 标签使用按缩放反算的字号，并做简单碰撞避让：缩放后只显示不重叠的标签，避免整屏名字挤在一起；
- 图片组节点不再只显示「N 张图」：优先使用图片 caption/OCR 描述作为标题，文档名 + 图片数量作为副标题；
- 分组图关闭初始力导向，使用稳定的分区布局，避免第一屏实体集互相挤压。

### 1.7 跨图桥接视觉

- `study_map` 的六类来源节点与知识主题节点之间使用真实关系边；
- 非 topic 的来源组之间跨组边使用虚线橙色表达；
- 有跨组连接的来源节点加桥接高亮样式。
