# OpenStudy 0.6.1 发布说明：智能对话空题库跳转修复

> 版本号说明：0.6.1 是 0.6.0 的补丁版本，只修复交互 bug，不改变数据模型与功能范围。

## 修复内容

- **创建题库后不再显示「题库已建好 / 立即开始刷题」跳转卡**：
  - 新建题库时还没有题目，点「去刷题」会进入空题库，用户会误以为创建失败；
  - `bank_manage(create)` 不再返回 `jumpUrl`；
  - `AgentToolResult` 对 `create + totalQuestions=0` 增加兜底，不渲染题库跳转卡。
- **导入题目后仍正常出现刷题入口**：
  - `question_manage(batch_import)` 成功后，题库已有题目，继续显示「题目已导入 / 去刷题」卡；
  - `bank_manage(open)` 对已有题库仍按用户显式请求显示「题库入口」。
- 创建成功提示改为「题库已创建成功，还没有题目，导入题目后再开始刷题」，与真实状态一致。

## 验证

- 后端编译通过；
- 前端 `npx vite build --mode development` 通过；
- 目标行为：创建题库的工具结果不再出现跳转卡；导入题目后才出现刷题入口。
