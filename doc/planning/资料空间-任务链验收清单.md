# 资料空间任务链验收清单

## 复制给测试助手的提示词

```text
请验收 OpenStudy「我的资料」任务链，不要新增任何 UI 组件。

测试目标：
1. 上传一份测试文档后，文档状态应从「待解析」自动进入「解析中」，最终变为「可检索」。
2. 上传过程中刷新页面，状态不能回退，也不能永久卡在「解析中」。
3. 点击「整理」后生成预览；勾选一条剔除建议并应用，文档应自动重新建立索引，最终回到「可检索」。
4. 连续点击同一文档的「重新解析」或「应用整理」不应产生重复任务，也不应出现「重复提交已拦截」的报错。
5. 整理记录只能查看已确认的内容，不能再次勾选；已剔除的图片/文字应显示「已剔除」。
6. 整个页面不应出现「任务中心」「资料健康」等额外入口。

约束：
- 只使用「我的资料」现有入口
- 不修改测试用户已有资料
- 测试结束删除本次上传的测试文档
```

## 手工操作步骤

### 步骤 1：上传

1. 打开「我的资料」
2. 进入「默认资料夹」
3. 点击「上传文档」
4. 上传一份测试 txt/docx
5. 观察文档行状态：

```text
待解析 → 解析中 → 可检索
```

也可以在此期间刷新页面，状态应继续推进，不应卡死。

### 步骤 2：整理预览

1. 找到刚上传的文档
2. 点击「智能整理」
3. 在预览中确认：
   - 内容统计在底部，不需要勾选
   - AI 变更需要手动勾选
   - 建议剔除默认不勾选

### 步骤 3：应用整理

1. 勾选一条「建议剔除」
2. 点击「应用选中整理」
3. 观察文档状态：

```text
解析中 → 可检索
```

不应出现一直停留在「正在解析/向量化」的情况。

### 步骤 4：查看整理记录

1. 点击资料夹上方的「整理记录」
2. 找到刚才的记录，点击「查看变更」
3. 确认：
   - 标题是「整理记录 · 智能整理」
   - 已应用变更显示「已应用」
   - 已剔除项显示「已剔除」
   - 已剔除项不能再次勾选

### 步骤 5：重复点击

快速连续点击「更多 → 重新解析」两次，或者快速连续点击「应用选中整理」两次。

预期：

- 不应该出现「操作失败：重复提交已拦截」
- 不应该启动两条重复任务

### 步骤 6：清理

删除本次测试上传的文档。

## 验收通过标准

- 状态能从上传走到「可检索」
- 应用整理后能自动重新索引
- 页面没有任何任务中心/健康中心新入口
- 没有重复提交报错
- 整理记录只读且状态准确
