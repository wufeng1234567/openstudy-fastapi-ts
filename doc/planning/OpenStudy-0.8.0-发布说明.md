# OpenStudy 0.8.0 发布说明

> 版本主题：知识图谱与页面内链。把知识百科从「能读的主题页」推进到「页面之间能互相跳转、可手动维护、可回到实体关系」的一层。

## 一、页面内链

- 知识百科正文支持 `[[page:<id>|<锚文本>]]`，前端渲染为绿色下划线链接，点击直接打开目标主题页。
- 主题页详情新增「页面链接」区：
  - 「本页链接到」显示出链；
  - 「反向链接」显示哪些页面链接到当前页；
  - 支持手动添加、移除单条链接、刷新链接。
- 反向链接从正文实时解析，不维护第二套容易漂移的边表；删除页面时会把其他页面里的死链还原成普通文字。
- 链接生成有两条路：
  1. 主题页生成提示词要求模型只在候选主题页标题中选择，并写成 `[[主题页标题|正文原词]]`；
  2. 构建收尾按标题、aliases、实体名做最长匹配补链，跳过自链、单汉字、代码块、行内代码、Markdown 链接/图片、公式和已有链接。

## 二、知识百科内的融合图谱

- 保持「知识图谱 + 知识百科」融合，只保留知识百科一个入口；不再新增独立图谱页签。
- 知识百科内提供「主题页 / 知识图谱」双视图；图谱中一个百科页面对应一个节点，节点按页面类型着色。
- 点击节点打开该百科主题页，详情同时展示出链、反向链接、相关主题和来源内容。
- 节点大小按连接度公式计算，叶子小、枢纽大；点击节点会出现选中脉冲环并把节点放大，同时把节点移到左侧可视区域，右侧打开详情。
- 保留 WeKnora 式聚类轮廓、悬停邻接高亮、非邻接节点淡化、缩放/拖拽/背景平移、缩放后标签显隐等交互；色调使用 OpenStudy 的蓝、绿、橙、红体系。
- 主题页类型按实体类型与图上位置推导：`concept / entity / synthesis / comparison`，前端对应概念/实体/综合/对比颜色。

## 三、首次抽取增强

- 文档分块从只取前 12 个扩展为全文均匀采样最多 60 个，并按每批 8 个分块多次抽取，避免长文档只读到开头。
- 实体类型扩展为：概念、定理/公式、方法、人物、机构、事件、作品、术语、变量/符号、其他。
- 实体支持 `aliases`（同义名/缩写）与提及次数；关系类型扩展为 12 类，并保留方向、强度、来源 chunk。
- 单篇实体上限和关系上限提高；单批失败不丢其他批次，批次错误随文档结果返回。
- 主题页生成时把全部候选标题限制在前 80 个内，避免提示词过长；无效标题在落库前降级为普通文字。

## 四、兼容与边界

- 不引入 Neo4j：实体/关系仍使用 PostgreSQL 的 `rag_graph_entity` / `rag_graph_relation`，页面内链由正文 `[[page:id|...]]` 派生。
- 旧主题页的 `page_type=topic` 在页面链接刷新/构建时按实体类型回填为概念、实体、综合或对比。
- 手动编辑保留用户内容；「刷新链接」会按当前标题/别名重新补链，手动移除的链接在刷新后可能再次出现，这是刷新语义而不是丢失用户内容。
- 没有真实来源的小节、没有出现在正文中的手动锚文本、指向不存在页面的链接都不会被伪造。

## 五、验证

- `pytest tests/test_wiki_link_service.py tests/test_wiki_service.py tests/test_knowledge_graph_service.py`：18 项通过。
- 浏览器验证：知识百科主题页正文绿色链接可点击；详情页显示出链/反链与关联主题；知识百科内「知识图谱」视图一个百科页面一个节点，点节点打开详情。
- 抽取验证：小资料夹从旧版 10 个实体 / 8 条关系提升到 21 个实体 / 20 条关系，无批次错误。
