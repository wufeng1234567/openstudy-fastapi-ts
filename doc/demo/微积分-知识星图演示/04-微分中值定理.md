# 微分中值定理

## 一、罗尔定理

如果函数 f(x) 满足：

1. 在闭区间 [a,b] 上连续；
2. 在开区间 (a,b) 内可导；
3. f(a)=f(b)；

那么至少存在一点 ξ∈(a,b)，使得 f'(ξ)=0。

罗尔定理的几何意义是：在两端函数值相等的条件下，曲线上至少存在一条水平切线。

前置知识：微分中值定理建立在导数与微分之上。定理的条件和结论都围绕导数展开，因此学习本节前必须掌握导数定义、求导法则和连续函数的性质。

## 二、拉格朗日中值定理

如果函数 f(x) 在 [a,b] 上连续、在 (a,b) 内可导，那么至少存在一点 ξ∈(a,b)，使得

f(b)-f(a) = f'(ξ)(b-a)。

这个公式称为拉格朗日中值公式。它表明：函数在区间上的平均变化率，等于某一点处的瞬时变化率。

## 三、柯西中值定理

如果函数 f(x) 与 g(x) 在 [a,b] 上连续、在 (a,b) 内可导，且 g'(x)≠0，那么至少存在一点 ξ∈(a,b)，使得

[f(b)-f(a)] / [g(b)-g(a)] = f'(ξ) / g'(ξ)。

柯西中值定理是拉格朗日中值定理的推广；当 g(x)=x 时，就得到拉格朗日中值定理。

## 四、洛必达法则

对于 0/0 型或 ∞/∞ 型未定式，如果分子分母在去心邻域内可导，且分母导数不为 0，在满足极限存在的条件下，可以使用洛必达法则：

lim f(x)/g(x) = lim f'(x)/g'(x)。

使用洛必达法则前必须先确认未定式类型，不能对非未定式直接使用。

## 五、导数与函数性态

利用导数的符号可以判断函数的单调性：f'(x)>0 时函数单调递增，f'(x)<0 时单调递减。导数等于 0 的点可能是极值点，还需要结合二阶导数或符号变化进一步判断。

微分中值定理把函数在一个区间上的整体变化与某一点处的局部导数联系起来，是证明不等式、研究函数性质的重要工具。
