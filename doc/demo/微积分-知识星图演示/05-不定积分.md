# 不定积分

## 一、原函数与不定积分

如果区间 I 上存在函数 F(x)，使得对任意 x∈I 都有 F'(x)=f(x)，则称 F(x) 是 f(x) 的一个原函数。

如果 F(x) 是 f(x) 的原函数，那么 F(x)+C（C 为任意常数）也是 f(x) 的原函数。函数 f(x) 的全体原函数称为 f(x) 的不定积分，记作 ∫f(x)dx = F(x)+C。

不定积分是求导运算的逆运算，积分结果必须带积分常数 C。

前置知识：不定积分建立在导数与微分之上。原函数的定义直接使用导数，因此学习本节前应先掌握导数定义、基本求导公式和链式法则。

## 二、基本积分表

由基本求导公式可以反向得到基本积分公式，例如：

- ∫x^n dx = x^(n+1)/(n+1)+C（n≠-1）；
- ∫1/x dx = ln|x|+C；
- ∫e^x dx = e^x+C；
- ∫sin x dx = -cos x+C；
- ∫cos x dx = sin x+C。

基本积分表是计算复杂积分的基础，需要与求导公式对应记忆。

## 三、换元积分法

第一类换元法（凑微分法）利用复合函数求导的逆过程：如果被积函数可以写成 f(φ(x))φ'(x) 的形式，则可令 u=φ(x)，把积分转化为 ∫f(u)du。

第二类换元法通过引入新变量 x=φ(t)，把根式、三角有理式等复杂积分转化为更简单的形式。换元后要注意积分上下限或变量回代。

## 四、分部积分法

分部积分公式为：

∫u dv = uv - ∫v du。

它适用于两个函数乘积的积分，选择 u 和 dv 时通常遵循“反对幂指三”的顺序。分部积分常用于处理 x e^x、x sin x、ln x 等类型的积分。

不定积分是定积分和微积分基本定理的前置工具，熟练掌握基本积分表和两种换元方法非常重要。
