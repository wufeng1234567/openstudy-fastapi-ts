# 导数与微分

## 一、导数的定义

设函数 y=f(x) 在点 x0 的某个邻域内有定义。如果极限

lim(Δx→0) [f(x0+Δx)-f(x0)] / Δx

存在，则称函数 f(x) 在点 x0 处可导，该极限称为函数在 x0 处的导数，记作 f'(x0) 或 dy/dx|x=x0。

导数刻画的是函数在一点处的瞬时变化率。若把自变量变化量记为 Δx，函数增量记为 Δy，则导数就是 Δy/Δx 当 Δx→0 时的极限。

前置知识：导数与微分以连续为基础。只有函数在点 x0 处连续，才可能在该点可导；但连续不一定可导。因此学习本节前应先掌握连续与间断。

## 二、导数的几何意义

函数 y=f(x) 在点 (x0,f(x0)) 处的导数，等于曲线在该点处切线的斜率。切线斜率反映了曲线在该点附近的变化方向。

导数的物理意义是瞬时速度：如果位移函数为 s(t)，则 s'(t) 表示时刻 t 的瞬时速度。

## 三、求导法则

常用求导法则包括：

- 常数的导数为 0；
- 幂函数 (x^n)' = n x^(n-1)；
- 和、差、常数倍法则；
- 乘积法则：(uv)' = u'v + uv'；
- 商的法则：(u/v)' = (u'v - uv') / v²；
- 复合函数求导法则（链式法则）：dy/dx = dy/du · du/dx。

基本初等函数的导数公式需要熟记，并结合复合函数求导法则处理复杂函数。

## 四、高阶导数

如果函数 f'(x) 仍然可导，那么它的导数称为 f(x) 的二阶导数，记作 f''(x)。二阶导数描述变化率的变化率；在物理中，位移对时间的二阶导数是加速度。

## 五、微分

函数 y=f(x) 在点 x 处的微分定义为 dy = f'(x) dx。微分是函数增量的线性主部，常用于近似计算和误差估计。

可导与可微在单变量函数中等价。导数与微分是后续学习中值定理、积分和微分方程的基础。
