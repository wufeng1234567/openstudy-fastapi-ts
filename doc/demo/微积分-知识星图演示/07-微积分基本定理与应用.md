# 微积分基本定理与应用

## 一、微积分基本定理

微积分基本定理揭示了微分与积分之间的互逆关系。设 f(x) 在 [a,b] 上连续，F(x) 是 f(x) 的一个原函数，则

∫[a,b] f(x)dx = F(b)-F(a)。

这个公式称为牛顿-莱布尼茨公式。它把定积分的计算转化为求原函数在端点处的函数值之差，是微积分中最重要的公式之一。

前置知识：微积分基本定理建立在定积分之上。理解定积分的定义、性质和变上限积分，是掌握牛顿-莱布尼茨公式的前提。

## 二、定积分的换元与分部积分

定积分也可以使用换元积分法和分部积分法。换元时，积分上下限要随新变量同步变换；分部积分时，要正确处理边界项。

例如，计算 ∫[0,1] x e^x dx 时，可以令 u=x、dv=e^x dx，得到结果为 1。

## 三、定积分的几何应用

定积分可以用来计算：

- 曲边梯形的面积：A = ∫[a,b] |f(x)|dx；
- 两条曲线之间的面积：A = ∫[a,b] |f(x)-g(x)|dx；
- 旋转体体积：绕 x 轴旋转时，V = π∫[a,b] f(x)^2 dx；
- 平面曲线的弧长和物理中的功。

建立积分表达式时，要先画图确定积分区间和被积函数，再代入公式计算。

## 四、反常积分

如果积分区间无限，或者被积函数在积分区间内存在无穷间断点，相应的积分称为反常积分。反常积分通过取极限来定义：先计算有限区间上的定积分，再令边界趋于无穷或间断点。

判断反常积分是否收敛，需要计算极限是否存在且有限。收敛的反常积分可以像普通定积分一样参与运算。

## 五、知识结构总结

微积分的主线可以概括为：函数与极限 → 连续 → 导数与微分 → 微分中值定理 → 不定积分 → 定积分 → 微积分基本定理。每一层都以前一层为基础，最终形成完整的微积分知识网络。
