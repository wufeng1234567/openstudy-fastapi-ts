# 函数与极限

## 一、函数的概念

设 x 与 y 是两个变量，如果对于 x 的每一个取值，按照某种对应法则，y 都有唯一确定的值与之对应，那么称 y 是 x 的函数，记作 y = f(x)。其中 x 称为自变量，x 的取值范围称为定义域，y 的对应值组成的集合称为值域。

函数是微积分研究的对象。常见函数包括一次函数、二次函数、指数函数、对数函数、三角函数和复合函数。判断两个函数是否相同，要看定义域和对应法则是否都相同，而不能只看解析式。

## 二、数列极限与函数极限

极限描述的是“无限接近”的过程。对于数列 {a_n}，如果当 n 无限增大时，a_n 无限接近常数 A，则称 A 是数列的极限，记作 lim(n→∞) a_n = A。

对于函数 f(x)，如果当 x 无限接近 x0 时，f(x) 无限接近常数 A，则称 A 是函数在 x0 处的极限，记作 lim(x→x0) f(x) = A。函数在 x0 处是否有极限，与函数在该点是否有定义无关。

左极限和右极限分别描述从左侧、右侧接近时的趋势。函数极限存在的充要条件是：左极限与右极限都存在并且相等。

## 三、无穷小与极限运算法则

如果当 x→x0 时，f(x) 的极限为 0，则称 f(x) 是 x→x0 时的无穷小。有限个无穷小的和仍然是无穷小；有界函数与无穷小的乘积也是无穷小。

极限具有四则运算法则：在参与运算的各个极限都存在的前提下，和、差、积、商的极限等于极限的和、差、积、商。使用商的极限法则时，分母的极限不能为 0。

## 四、夹逼定理

如果存在三个函数 g(x) ≤ f(x) ≤ h(x)，并且当 x→x0 时，g(x) 与 h(x) 的极限都等于 A，那么 f(x) 在 x→x0 时的极限也等于 A。夹逼定理常用于处理含有三角函数、绝对值或振荡因子的极限。

## 五、本节在微积分中的位置

函数与极限是微积分的第一块基石。连续、导数、定积分等概念都建立在极限之上。学习后续内容前，需要能够熟练计算基本极限，并理解“无限接近”的含义。
