name: 避免索要用户明文密钥，改用占位符/环境变量
description: 涉及令牌/密钥等敏感凭据时应引导用户通过占位符或环境变量传递，不要让其明文贴进对话
type: feedback
from: Agent
---

涉及 PAT、API Key、密码等敏感凭据时，不要要求用户明文贴进对话；应让其通过占位符、环境变量或本地配置传递。若用户已明文给出，处理完须提醒其立即吊销/重置。

**Why:** 2026-10-09，为自动化建仓向用户索要 GitCode PAT，用户直接把明文令牌发到了对话里，造成凭据暴露风险。
**How to apply:** 凡是需要凭据的自动化操作（建仓、推送、调第三方 API），优先让用户把值写入本地环境变量或 `.env`（并确保其被忽略），由脚本读取；绝不在对话中要求回显明文。若已泄露，第一时间提示吊销。
