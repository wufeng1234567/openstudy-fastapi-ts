当前 OpenStudy 智能体 UI **面向用户能操作的只有「是否关闭专家」**（专家=子代理），**没有任何开关能屏蔽/关闭单个工具**。

**Why:** 2026-10-11 排查「子代理工具集为空」时，Agent 一度误以为「用户自己把关工具全关了」。用户明确澄清**从未屏蔽过任何工具**，UI 上也无此能力。故**持久化层 `ai_agent_tool_pref` 里的全量禁用数据绝非用户主动行为，只能是旧 UI 遗留/前端 bug 残留**。这直接决定了修复方向：不能把「恢复能力」寄望于让用户去 UI 里把工具打开（他根本打不开），**必须从代码层修**（子代理 exclude 不读 `user_disabled`）。

**How to apply:** 涉及「用户屏蔽/偏好」的排查时，先认清 UI 实际能力边界（本产品=仅专家开关）。凡发现 DB 里存在用户 UI 无法产生的偏好数据（如全量工具禁用），一律按**残留/旧 bug 产物**处理，走清数据+代码兜底，而非向用户索要操作步骤。
