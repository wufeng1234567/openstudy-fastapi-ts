name: 用户输入过短/含糊时 LLM 应简短澄清而非擅自深挖与调工具
description: 2026-10-11 用户要求——遇到"1"这类歧义短输入，模型须先简短询问意图，不要自顾自深度思考并调用一堆工具
type: feedback
from: Agent
---

**当用户输入过短或含义含糊时（如只回一个数字 "1"），模型必须先用一句简短的问话澄清用户意图，不得擅自展开深度思考、自作主张调用一堆工具、给出冗长的无关回复。**

**Why:** 2026-10-11 用户反馈"我输入一个 1 时莫名其妙 llm 就深度思考一堆东西、然后自顾自地给我调用一堆东西"，明确要求「**需要跟他说清楚，让他简短的回复用户想要看嘛**」。这是**教育/学习类 C 端产品**的取向——回复应短、贴合用户当下意图，而非秀模型能力的炫技式长输出。
**How to apply:** 该约束落实在 `openstudy-fastapi/app/services/ai/prompts.py` 的 `AGENT_WORKFLOW_RULES`（系统提示词）中：新增一条"歧义/过短输入先澄清"规则，示例**必须用英文**（P11d 白名单禁新增系统提示词中文，见 feedback-probe-model-side-chinese-whitelist）。此规则与 `feedback-no-json-raw-jargon-to-end-users` 同属"面向 C 端用户、说人话、别啰嗦"的持续取向。
