用户 2026-10-22 明确要求：**「你不要每次完成任务就杀程序」**。

## 背景

此前多次出现：Agent 做完改动后，为「清理环境」主动 `Stop-Process` 掉
uvicorn / vite / Chrome 等进程，导致用户正在使用的服务突然中断，
用户还得重新启动一遍。

## 规则

1. **默认不杀进程**。改完代码、跑完测试、提交完代码之后，
   服务该留着就留着，不要"顺手清理"。
2. **只有用户明确说「关掉 / 停掉 / 交给我启动」时才停服务。**
   例如「把前后端都关掉，我自己启动」——这种才执行停止。
3. **重启后端用于让改动生效是允许的**，但那是"重启"不是"关闭"，
   且应在同一轮操作里重新拉起，不要停在关闭状态。
4. 临时启动的测试载体（如截图用的无头 Chrome）可以关，
   但**前后端主服务不要碰**。

## Why

用户的开发节奏是边看边改：Agent 一停，浏览器就打不开，
前面的验证上下文也断了。停服务对他只有成本、没有收益。

## How to apply

- 完成任务后的收尾动作：**不包含停服务**。
- 需要重启时：先说明"我重启一下后端让改动生效"，然后重启，保持运行。
- 用户说停才停；停之前确认是哪些服务（前端 / 后端 / 全部）。
