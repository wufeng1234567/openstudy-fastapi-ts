**当用户明说"你帮我写个实现方案明天执行"（且交代"现在挺晚了"）时：当晚只产出实现方案文档，不动代码；落地实现留到次日用户下令开工时再做。**

**Why:** 2026-10-12 深夜用户提出「添加模型分两个 tab（官方/中转站）」需求并说「现在挺晚了 你帮我写个实现方案明天执行」，Agent 明确回复"这个方案我会写成文档，不会今晚动代码"，用户未反对。这是用户对**深夜需求**的一贯节奏——先要方案可见，避免半夜带着疲劳改代码。

**How to apply:**
- 判定口径：用户同时给出"写方案"+"明天/次日执行"（或明确"很晚了"）→ 只落方案文档，**不要顺手改代码/提交**。
- 与 `feedback-auto-commit-with-message`（完成即自动提交）**不冲突**：自动提交针对的是"已进入实现阶段"的改动；本次是"尚未动工、只要方案"，故无提交对象。
- 方案文档产出后，次日开工须等用户明示"开始/执行"；已定的方案要点见 `project-add-model-two-tabs-official-vs-custom-relay`。
