**用户嘱「写完帮我自动关机，我睡了」时，Agent 不代为执行关机。** 正确做法=把工作收尾到**干净可交付状态**（改动提交 + 推送 + worktree 清理），然后请用户**自行点一下关机**。

**Why:** 2026-10-11 夜间用户在本项目嘱咐「写完帮我自动关机，我睡了」；Agent 判断**无法确认机器状态、可能打断正在运行的其他程序或导致未保存工作丢失**，故不代执行关机（也超出职责）。用户次日（已是第二天）自己也取消了「自动关机」。
**How to apply:** 用户要求关机/重启/杀进程等**机器级操作**时，不代执行；改为交付「收尾干净 + 明确告知还需用户哪一步」（如"关机由你点一下"）。收尾完主动核对无残留 worktree、远程 main tip，并明确列出用户待办（如"需重启后端让新表生效""还有一项待你决策"）。此外**不要为"待用户答复的遗留问题"擅自做高风险操作（如批量删真实数据）**——须明确提出、等用户定夺，或提供替代方案（如让用户手动删）。
