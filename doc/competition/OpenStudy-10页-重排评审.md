# OpenStudy 10 页比赛版重排评审（评委 / 产品负责人视角）

> 评审对象：`doc/competition/OpenStudy-10页-码道版.pptx`（0.8.0，当前 10 页）
> 评审标准：① 可演示作品，优先做透一个痛点；② 叙事必须是「解决谁的什么问题 → 怎么用码道做出来的 → 现场演示要点 → 后续迭代计划」，总页数 ≤ 10。

## 结论先说

当前版本的问题不是“页数不够”，而是“主角迟到”：

- P1 承诺“能查、能练、能追到原文”，但唯一能证明“能练”的「资料到题库」被放在 P6；前五页没有一页真正展示“资料变成题”。
- P2–P5 实际是「痛点 → 体检 → 图谱 → 处方 → 题库」四个功能并列，像功能目录，不像一个用户的一条故事。
- 现有素材库里至少有四套样本，当前 PPT 混用了其中三套：高数 Word（3 小问/3 公式/1 区域图）、文本型 OpenStudy 文档（27 章/2790 字/0 图/0 题/75 分）、概率论复习题（72 分/13 图/26 题 + 7 天处方）；另外还有物理讲义（78 分/5 章/3 图/0 题）容易被误用。评委只要问一句“这份资料到底是哪一份”，故事就断了。
- P4 左边图谱选中“导数”，右侧详情却是“智能体”，同一页两个主题；这是最容易被现场抓住的硬伤。

重排的核心动作只有三个：

1. 把「资料到题库」从 P6 提到 P3，做全场主角；
2. 把「资料诊疗室」从独立功能页降为 P3 顶部的一条“体检结论” + P9 现场演示步骤；
3. 把「码道开发」从 1 页拆成“方法 + 真实案例”2 页。

## 1. 唯一核心痛点

**一句话：理工科备考者的题目被困在 Word/PDF 里——公式会乱、图会丢、题做完找不到知识点和原文，所以资料再多也练不起来。**

### 为什么是它

1. **它是“资料”到“学习”的唯一断点。** 不解决这一步，知识图谱只是好看，规划建议只是通用计划，资料库只是另一个网盘。
2. **它可以用一张前后对比证明。** 左边 Word 里的 3 道题，右边同题可刷；公式、区域图、知识点、题源 chunk 四个都在。评委 10 秒就能看懂。
3. **它逼出真正的技术护城河。** OMML→LaTeX、图片锚点、题目→知识点、题目→原文 chunk——这些不是通用聊天能替代的，正好是 OpenStudy 的差异点。
4. **它给其他功能分配了角色。** 体检决定“这份资料能不能出题、先补什么”；知识图谱回答“这题属于哪一节”；规划建议回答“下一步练什么”；码道回答“这条链怎么造出来”。四个功能不再并列，而是同一痛点的四个连续动作。
5. **它适合现场演示。** 本地 Word、预置题库、固定账号，3 分钟能走完；不依赖长等待的模型生成。

### 不是什么（为什么排除其他痛点）

- **不是“资料找不到/太乱”。** 网盘、笔记、搜索都能解决，差异化弱。
- **不是“不会做学习计划”。** 通用 AI 也能写一份计划，评委很难判断有效性。
- **不是“AI 黑盒不可信”。** 重要，但太抽象；放在技术页做支撑，不做第一痛点。

### 一句话故事线

一份高数 Word（3 小问 / 3 个主公式 / 1 张区域图）→ 体检发现第二章缺练习 → 3 小问变成可刷题（公式、图、知识点、题源全带）→ 做错第 3 题，追到主题页和原文 chunk #693/第 2294 段 → 生成 7 天处方；这条链是码道按“读仓库 → 拆任务 → 子代理 → 自测 → review”做出来的。

## 4. 现场演示必须讲透的 3 页

**P3、P4、P5。** P9 是演示脚本页，不算产品核心页；它负责把这三页串起来。

### P3：资料→题（全场胜负手）

- 先给结果，不要先念五步流程。
- 让评委看左右同题：左边 Word 的 3 小问 + 区域图，右边刷题页的同一道题。
- 停 3 秒在三个标注上：公式已变 LaTeX、区域图随题、题源 #693/第 2294 段。
- 一句话：“以前题在 Word 里，只能看；现在题在题库里，能刷、能判、能追。”

### P4：知识图谱（证明不是死路）

- 只追一条链：点知识点 chip → 同名主题页 → 来源/原文 chunk。
- 不要展示整张图谱的所有节点；只让评委看“出链 / 反链 / 来源 / 版本”四个标签。
- 一句话：“做错一道题，不是只记一个错号，而是回到它对应的那一节、那一段原文。”

### P5：规划建议（证明有下一步）

- 只讲一个依据：第二章缺练习 → Day1 补第二章 2 题。
- 不要念完整 7 天计划；让评委看到“每条任务都能查看原文 / 去练习”。
- 一句话：“处方不是通用计划，是从这份资料的体检和这道题的错因里长出来的。”
