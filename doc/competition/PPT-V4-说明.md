## 一、本版修正的过时内容

- 版本从 0.7.2 更新到 0.8.0；
- 删除“学生不缺资料/题库”的单一学生叙事，改成“理工科备考者”的一个真实场景；
- 删除“资料诊疗室三步 = 体检 / 整理 / 学习处方”的旧主线；
- 以当前系统的「资料 → 资料诊疗室 → 知识百科/知识图谱 → 规划建议 → 题库」为主线；
- 知识图谱口径修正为：题库、资料、网页、笔记、图片五类来源抽取、归并成知识主题；图谱首层只展示知识主题，来源实体在主题详情里展开；
- 补充当前截图：资料空间、资料诊疗室、知识主题图、主题详情、规划建议。

## 二、10 页结构

| 页 | 内容 | 比赛要求 |
|---|---|---|
| P1 | 封面：告别赛博仓鼠 + 知识图谱 | 作品第一眼 |
| P2 | 一个真实用户：高数 Word 导入题库，一晚上一道题没刷成 | 解决谁的什么问题 |
| P3 | 收进来：同一份 Word 变成可刷题，公式/图/知识点/题源都在 | 可演示核心功能 |
| P4 | 连起来：知识图谱自动抽取节点，承接题库 | 可演示核心功能 |
| P5 | 知识百科：LLM 把每个节点整理成可读的知识页 | 可演示核心功能 |
| P6 | 系统基石：Agent Runtime + 一切皆对话 | 技术实现质量 |
| P7 | 码道方法：读仓库、拆任务、跑验证、做 review | 码道开发 |
| P8 | 码道证据：prompt → file:line → todos → review | 码道开发 |
| P9 | 现场演示：3 分钟重走一份 Word 的真实链路 | 现场演示要点 |
| P10 | 迭代计划与团队分工（含知识图谱 2D → 3D 探索） | 后续迭代计划 |

## 三、版式要求

- 16:9，浅色底、薄荷绿主色；
- 标题大、正文少、每页一个主结论；
- 截图按实际运行界面展示，不用纯装饰图；
- 不使用大面积空白，信息用卡片/流程条填满；
- 不写空泛口号，尽量使用可演示、可核对的动作和数据。

## 四、重建

```powershell
# 1. 生成 PPT
openstudy-fastapi\.venv\Scripts\python.exe doc\competition\build_ppt_v4.py

# 2. 导出 PDF
pwsh -NoProfile -File doc\competition\pdf_v3.ps1

# 3. 导出逐页 PNG
pwsh -NoProfile -File doc\competition\export_v3.ps1
```

## 五、备注

- 唯一用户痛点：考试周高数资料很多，却凑不出一套能刷的题；
- 核心演示链：P2 问题 → P3 自动提炼题库 → P4 知识图谱 → P5 知识百科；
- 每页页脚带 `Agent · 理解 → 工具 → 回执`，P6 单独讲 Agent Runtime 与“一切皆对话”；
- 专门演示资料夹：`OpenStudy 演示图谱 · 微积分`（kbId 645），文档 `微积分知识地图-演示.md`（docId 694）；
- 码道采用两页：P7 方法 + P8 真实证据（`codearts-fileline-2026-11-15.png`）；
- 旧版 `PPT-V3-说明.md` 仅作历史保留，不再作为当前比赛版说明。
