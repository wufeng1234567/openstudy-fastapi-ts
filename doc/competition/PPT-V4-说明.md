## 一、本版修正的过时内容

- 版本从 0.7.2 更新到 0.8.0；
- 删除“学生不缺资料/题库”的单一学生叙事，改成当前 README 的三类用户；
- 删除“资料诊疗室三步 = 体检 / 整理 / 学习处方”的旧主线；
- 以当前系统的「信息来源 → 资料诊疗室 → 知识百科 → 知识图谱 → 规划建议」为主线；
- 知识图谱口径修正为：题库、资料、网页、笔记、图片五类来源抽取、归并成知识主题；图谱首层只展示知识主题，来源实体在主题详情里展开；
- 补充当前截图：资料空间、资料诊疗室、知识主题图、主题详情、规划建议。

## 二、10 页结构

| 页 | 内容 | 比赛要求 |
|---|---|---|
| P1 | 封面：知识资产定位 + 知识图谱真实截图 | 作品第一眼 |
| P2 | 用户与问题：三类用户、共同问题 | 解决谁的什么问题 |
| P3 | 资料到题库：公式、图片、知识点都不丢 | 可演示核心功能 |
| P4 | 资料诊疗室：体检 / 原文 / 报告 | 可演示核心功能 |
| P5 | 知识百科 × 知识图谱：主题与来源 | 可演示核心功能 |
| P6 | 规划建议：从真实图谱路径出发 | 可演示核心功能 |
| P7 | 技术实现：轻量自研与可信链路 | 技术实现质量 |
| P8 | 怎么用码道做出来：8 环节流水线 + 真实过程记录 | 码道开发 |
| P9 | 现场演示：3 分钟真实链路 | 现场演示要点 |
| P10 | 迭代计划与团队分工（含知识图谱 2D → 3D 探索） | 后续迭代计划 |

## 三、版式要求

- 16:9，浅色底、薄荷绿主色；
- 标题大、正文少、每页一个主结论；
- 截图按实际运行界面展示，不用纯装饰图；
- 不使用大面积空白，信息用卡片/流程条填满；
- 不写空泛口号，尽量使用可演示、可核对的动作和数据。

## 四、重建

```powershell
# 1. 生成 PPT
openstudy-fastapi\.venv\Scripts\python.exe doc\competition\build_ppt_v4.py

# 2. 导出 PDF
pwsh -NoProfile -File doc\competition\pdf_v3.ps1

# 3. 导出逐页 PNG
pwsh -NoProfile -File doc\competition\export_v3.ps1
```
