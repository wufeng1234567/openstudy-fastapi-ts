## 一、为什么要改（V1 体检数据）

| 页 | 最小字号 | ≤10pt 文字占比 | 单页字数 |
|---|---|---|---|
| P1 封面 | 8.0pt | 65% | 313 |
| P3 方案 | 7.5pt | 62% | 395 |
| P4 完成度 | 7.5pt | 68% | 430 |
| **P5 技术** | **6.0pt** | **76%** | **688** |

| **P7 码道②** | **7.0pt** | **84%** | **852** |

| P10 迭代 | 7.5pt | 87% | 543 |
| **全篇** | **6.0pt** | **76% 平均** | **5,475 字（547/页）** |

**三个病**：
1. **不说人话** —— 术语堆砌（Orchestrator / RRF k=60 / confirm_ticket / 整树快照），评委看不懂
2. **结构不对** —— 没有严格四段式；技术架构单独占一页，码道拆三页互相重复
3. **风格太重** —— 整页黑底 + 满屏文字，与"清新、清晰"完全相反

**判分现实**：初筛 = 主观评分 + AI 评分，取前 20 名进线下路演。
→ AI 评分读的是**文字可读性**，评委看的是**画面第一印象**。V1 两头都不占优。

## 五、文案改写对照表（说人话）

| V1 写的 | V2 改成 |
|---|---|
| Orchestrator（关键词路由，零 LLM）→ 5 类专家子代理 → 14 个工具（统一 `{success,error,hint}` 信封） | 你说一句话，它先判断该找哪个助手，再派对应的助手去做 |
| RRF（k=60）融合 HNSW 余弦 + tsvector GIN | 用两种方式找资料，再把两边结果合并 |
| confirm_ticket 二次确认 + 四域整树快照 | 改数据前先问你一句；改错了能一键撤回 |
| 629 次读 + 667 次改 + 1,658 次命令 | 它先读代码、再改代码、然后自己跑一遍验证 |
| 80 秒内连读 registry.py / loop.py / rag_write_service.py / document_pipeline.py | 它先花 80 秒，把 4 个关键文件读了一遍 |
| 多专家并行，单专家隐身 | 一件事要两个人干，就同时干；一个人能干，就不打扰你 |

**一条铁律**：屏幕上出现的每个词，都要能让**没写过代码的人**看懂。
技术名词只留在讲稿 / 备注里。

## 六、核心功能怎么讲（本次重点补充）

用户指定的核心链路（文案已优化）：

> **上传一份 Word / PDF / Markdown → 自动解析 → 导入系统 → 直接开刷**

**V2 的 P3 就讲这条线，四步各配一个"看得见"的结果**：

| 步骤 | 屏幕文案 | 一句话解释 | 配图 |
|---|---|---|---|
| ① 上传 | 传一份资料 | Word / PDF / Markdown 都行，带公式和图片也能读 | `01-agent-chat.png` 或上传按钮 |
| ② 自动解析 | 它自己读懂 | 拆成段落、认出公式、把图片抠出来，转成能检索的知识块 | `02-agent-session.png`（出题过程） |
| ③ 导入系统 | 变成你的题库 | 按原文出题，每道题标注出处；也可以整份文档直接入库 | `02-agent-session.png` |
| ④ 开刷 | 直接开练 | 顺序刷 / 随机刷 / 只刷错题 / 模拟考，答完自动判分 | `04-bank-detail.png` |

**这四步就是我们跟"普通 AI 聊天框"的分界线**——聊天框给不了你一个能刷的题库。

### 补充：RAG 那页怎么放（可选加分）

如果评委问"知识库跑在哪"，可以直接切到 `07-rag-config.png`：

> **本地优先，云端可选。** 默认在本机加载向量模型，文档不出内网；
> 轻量服务器上可以一键切到云端，不用下载 2.2GB 模型。
> 这个开关在后台可视化配置，改完即时生效。

**这段话能直接回应"技术实现质量"里的"工具使用是否规范"** —— 说明我们考虑过部署环境差异。

## 六之二、迭代计划怎么写（P9 用）

赛事要求"后续迭代计划"，不要写成愿望清单。按**问题 → 方案 → 验收**写：

| 阶段 | 事项 | 一句话理由 |
|---|---|---|
| **30 天** | 扫描版 PDF 接 OCR | 高校最常见的资料形态，现在抽不出正文 |
| | Markdown 图片解析 | `![](url)` 外链图现在不进知识库 |
| | 入库入口统一 | 页面上传和对话入库对图片处理不一致 |
| **90 天** | 多模态向量（以图搜图） | 现在搜不到"那张电路图" |
| | 移动端适配 | 补响应式布局 |
| | 对象存储直传 | 摆脱本地磁盘依赖 |
| **更远** | 校园版多租户 / 教师端 | 从个人工具走向教学基础设施 |
| | 开放 API | 接入教务系统、题库供应商 |

> 完整版见仓库 `doc/ITERATION-PLAN.md`。
