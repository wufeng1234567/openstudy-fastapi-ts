# 用华为云码道 CodeArts 开发 OpenStudy

> 本文说明本作品如何在**华为云码道 CodeArts（在线工作台）**中开发，以及开发过程留下的工程记录。
> 开发环境：华为云 → AI 开发者空间 → 码道 CodeArts 代码智能体（在线 TUI / IDE）
> 代码托管：GitCode

## 一、开发环境与仓库

| 项 | 说明 |
|---|---|
| 工作台 | 华为云 AI 开发者空间 · 码道 CodeArts（在线） |
| 代码仓库 | GitCode 公开仓库 |
| 主要分支 | `main`（稳定）/ `feat/*`（迭代） |
| 后端 | Python 3.11 + FastAPI + PostgreSQL 16 + pgvector |
| 前端 | Vue 3 + TypeScript + Vite |

## 二、固定的开发流程

1. **需求进对话**：一句话说清目标与验收标准。
2. **先读后写**：`grep` / `read` 定位到具体文件与行，再动手。
3. **计划拆解**：复杂任务先出步骤（todo），执行中逐项勾掉。
4. **改完自测**：跑 `compileall`、`pytest`、探针，失败自己修到过。
5. **代码审查**：`code-reviewer` 按 P0/P1/P2 出报告，修完再提交。
6. **规范提交**：中文提交信息，推到 GitCode。
