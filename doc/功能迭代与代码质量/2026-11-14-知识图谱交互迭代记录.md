# 2026-11-14 知识图谱交互迭代记录

> 说明：本文记录的是 OpenStudy 当前的「知识百科 / 知识图谱」实现，
> **不是已废弃的「知航 · 星图」计划**；该历史计划仅归档，不继续迭代。

## 本轮确认的结果

- 用户确认：鼠标快速移动、在不同节点之间切换时，hover 动画已经跟手，整体手感通过。
- 大图场景：`kb604`，345 个主题节点、691 条边。
- 性能采样目标：hover 切换不再出现整图节点逐个 patch 和 SVG opacity 重绘。

## hover 及其性能改动

1. 基础节点和基础边分别包成一个 SVG `<g>`：
   - `.kw-map-base-nodes`
   - `.kw-map-base-edges`
2. hover 时只切换这两个组的透明度，不再给 345 个节点逐个设置 `opacity`。
3. hover 高亮使用独立轻量覆盖层：
   - 只渲染当前节点、少量邻居节点；
   - 只渲染当前节点相关边；
   - 覆盖层 `pointer-events: none`，不干扰节点命中。
4. 基础节点使用 `v-memo`，hover 变化不重渲染 300+ 个基础节点。
5. 每个节点增加透明命中圈，覆盖圆点、光环、文字之间的空隙。
6. hover 进入下一帧立即响应；离开保留约 70ms 缓冲；避免外围反复 enter/leave 导致闪烁。
7. 大图模式隐藏 hover 时的装饰光环和学习环，减少 SVG 重绘。

## 节点拖拽修正

- 拖拽起点同步读取 `mapVisualTransform`，避免打开详情后相机快照仍是旧值。
- 拖拽过程只用「屏幕位移 ÷ 拖拽开始时的缩放」，不再每个 `pointermove` 读取 SVG rect。
- 拖拽开始使用 pointer capture，避免指针经过文字/覆盖层时丢失。
- `is-dragging` 期间隐藏 hover 覆盖层、恢复完整底图，减少重绘。
- 松手后不再根据节点位置平移/缩放画布，节点严格停在拖拽位置，避免 `B+10` 的落点偏差。

## 点击节点打开抽屉优化

点击节点时不再同时执行 360ms 镜头动画和抽屉入场：

- 选中节点后立即把画布切换到目标视角，不做长时间镜头动画；
- 下一任务立即打开抽屉；
- 抽屉先用加载骨架，再异步填充 `getWikiPage` 内容；
- 增加 `graph-detail-open` / `graph-detail-loaded` 性能标记，写入现有性能日志的 `action` 字段，后续可直接按耗时排查。
