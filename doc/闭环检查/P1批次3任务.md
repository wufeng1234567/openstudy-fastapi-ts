# P1 批次 3 任务

- 日期：2026-11-03
- 目标：清理 P1 批次 2 记录中剩余的 P1/P2 主链路项，并以真实接口/数据库/页面验证
- 自动 Review：完成实现后由独立子代理复核，主代理逐条处置

## 一、范围与验收标准

### A. 题库练习（最高优先级）

- [ ] 新增服务端练习会话/成绩快照，刷新/换设备后可通过接口回看
- [ ] 练习题目初始载荷不包含 `answer` / `analysis`
- [ ] 客观题由服务端按题库标准答案判分，不再信任客户端 `isCorrect`
- [ ] 简答题标记 `pending`，不按字符串全等判错、不写错题本
- [ ] 模拟考试交卷走服务端会话/判分，成绩与错题进入统计
- [ ] 前端顺序/随机/错题/模拟四条练习路径 build 通过并至少实测顺序练习作答

### B. 题库搭建

- [ ] 新增 `saveWithQuestions` 单事务保存接口：题库信息 + 题目新增/更新 + 子题替换 + 显式删除
- [ ] 任一步失败整体回滚，不留半成品
- [ ] 前端保存改为一次请求；新建/编辑/删除题目的结果与列表一致

### C. 个人中心 / 我的资料

- [ ] 头像只接受真实图片（扩展名 + magic bytes），更新后清理旧本地头像
- [ ] 改密/管理员重置密码后，该用户全部旧 token 失效
- [ ] 请求校验失败统一 `{code:422,msg:...}` 信封
- [ ] 知识库上传后文档数立即刷新；同名资料拒绝重复上传
- [ ] 删除资料/知识库时清理本地图片等物理文件
- [ ] 上传后多文档状态轮询合并为一次批量请求
- [ ] 低置信检索不再把 top_k 条噪声全部展示

### D. 英语学习

- [ ] OCR 完成面板「马上听写」携带刚导入的 bookId 跳转
- [ ] 阅读练习短文/题目/答案随成绩落库，可回看
- [ ] 词书列表/详情/单词列表对非归属用户统一 404，不泄露

### E. 消息中心 / 学习分享

- [ ] 进入消息中心不再拉全量 `listAll` 三次；红点用服务端聚合接口
- [ ] 系统/用户通知列表支持分页与 scope 过滤
- [ ] 标已读失败回滚 UI 并提示，不出现刷新后回弹
- [ ] 笔记/评论正文服务端 HTML sanitizer，拦截 script/事件属性/javascript 协议
- [ ] 笔记编辑页离开时对未保存修改弹确认

### F. 后台管理

- [ ] `/monitor/server`、`/monitor/cache*`、`/monitor/online*` 返回真实数据，普通用户 403
- [ ] 无后端实现的监控菜单隐藏
- [ ] 角色/部门/菜单新增、修改、删除可用并实测
- [ ] 服务监控页不再出现“Java/JVM”错误文案

## 二、验证方式

- 后端：`compileall` + 真实 HTTP（user1/user2/admin 三种身份）+ PostgreSQL 查询
- 前端：`npm run build:prod` + 关键页面 CDP 截图/点击
- 数据：临时记录统一 `audit_` 前缀，验证后清理；不改演示数据基线

## 三、不在本批伪装完成的范围

- 需要外部 OCR/大模型质量、跨设备真实浏览器并发、1000 题压力测试
- 后台没有数据表的定时任务/操作日志/登录日志：本批隐藏菜单，不伪造空接口
