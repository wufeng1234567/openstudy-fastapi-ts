## 三、P1 重点（按主题归并）

### 3.1 权限与隐私

- 英语学习：`new-words`/`mastery` 未校验词书归属；`words/export`、`wordBooks/export` 无用户过滤（user2 实测导出 user1 词书/全部词书）。
- 个人中心：编辑资料 JSON body 被后端 Query 签名忽略，200 但数据不变；`updatePwd` 可设 1 位密码且密码走 URL query；业务错误统一 code=500。
- 题库练习：判分/答案可信度依赖前端，后端接受 `isCorrect`；论文题字符串相等判错。
- 题库搭建：编辑页加载失败 `questions=[]` 后保存会删光旧题；删题无确认；保存逐题串行、非原子。

### 3.2 数据一致 / 假成功

- 全局 `catch_all.py`：未知 API 返回 `200 {code:200,data:null}` 或空分页；消息/后台/我的资料/学习分享多处“假成功”根因。
- 消息中心：`sys_notice.create_time` 22/25 为 NULL，排序把旧通知排最前；系统通知与分享通知两套 unread 未聚合。
- 我的资料：KB `docCount/chunkCount` 上传后滞后，失败态永久 0；`kbShare` 误判空库；删除不清理物理文件/关联记录。
- 我的学习：错题总数 75/90/125 三口径；`Promise.all` 让单接口失败整页空；`totalQuestions` 用收藏数。
- 消息中心：分享通知删除/清空无确认；公告隐藏不可恢复。

### 3.3 前端可用性 / 路由

- 我的学习：`/front/myQuestion` 根路径白屏（无重定向/空态）。
- 后台管理：20+ views 页面无路由/菜单，深链 404；角色/菜单/部门/字典、监控其余页、内容管理不可达；疑似未登录 `/index/home` 未跳登录（待人工复测）。
- 我的资料：上传轮询每轮全量 `/rag/workspace/overview`（x9）且超时静默；同名文件重复上传无提示；资料解剖/微课无 docId 错误态空白。
- 消息中心：进入子页重复 3 次 `listAll`；已读失败静默回弹；分享通知失败假空态；`createTime=null` 显示 1970。
- 个人中心：编辑弹窗手机/邮箱必填与存量空数据冲突，user1 无法保存；他人页分类错用访问者分类；假分页 pageSize=999。
- 英语学习：`due?bookId=128` count=20、returned=0；OCR“马上听写”不带 bookId；听写刷新不恢复；阅读无后端题目接口。
- 题库练习：`recordStudyTime` 重复计时、`answeredCount` 对象 bug、NaN/null draft key、`byQuestionType` 用收藏等。

### 3.4 后台/监控

- `/monitor/**` 仅 ratelimit 8 个端点，在线/定时任务/日志/服务/缓存后端不存在，前端落 catch_all 空数据。
- 后台首页系统信息硬编码“MySQL”（实际 PostgreSQL）；登录页 demoMode/captcha 字段异常。

## 四、已验证通过的关键链路

- 智能对话：登录、会话列表、流式对话、历史消息基本可读；见报告。
- 题库练习：题库/练习页可加载，刷题流程有前端状态；但成绩不可信。
- 我的学习：统计/题库/笔记三页有真实数据；根路径问题已复现。
- 学习分享：笔记列表/详情/评论/收藏主链路可走通；点赞缺失。
- 题库搭建：建库/加题/保存主链路可用；异常路径有数据风险。
- 我的资料：建资料夹→上传文本→解析 status 5→搜索/问答→分享领取→删除全链路真实通过；跨用户 12 项 404。
- 英语学习：3 个词书/单词列表/练习统计/last/due 真实；练习提交/记忆曲线后端落库通过。
- 消息中心：用户隔离、markRead/delete 越权拦截、未登录 401、分享通知分页通过。
- 个人中心：本人资料读取、我的笔记/收藏/模型页面、他人公开笔记、未登录拦截通过。
- 后台管理：admin 登录/getInfo/getRouters、dashboard 统计、用户/角色/菜单/部门/字典/参数/评论/轮播列表、14 个可达页面巡检 0 JS error 通过。

## 五、建议修复顺序

1. **P0 安全**：公告写接口/AI 配置/`/rag/config` 加 `require_admin`；个人中心 `front/{id}` 裁剪 PII；智能对话会话归属；智能对话 GET 路由；学习分享点赞。
2. **P1 数据可信**：题库练习服务端判分/会话；英语导出/词书权限；消息 createTime/聚合未读；个人中心编辑 body/校验；我的资料 KB 计数/检索阈值；题库搭建编辑保护/保存原子性。
3. **P1 前端阻断**：我的学习根路径；后台死页面路由；消息确认/错误态；我的资料轮询；个人中心必填冲突。
4. **P2 清理**：catch_all、HTTP 4xx、物理文件/孤儿记录、假分页、演示数据残留、后台 MySQL 标签。
