## 一、修复清单

### A. 个人中心：编辑资料与密码契约

**修复**

- 新增 `ProfileUpdate` / `PasswordUpdate` Pydantic schema（`app/schemas/user.py`）。
- `PUT /system/user/profile` 改为 JSON body，服务端校验昵称、邮箱（有值才校验）、手机号（有值才校验）、性别。
- `PUT /system/user/profile/updatePwd` 改为 JSON body，服务端校验旧密码、新密码 6–20、不能与旧密码相同。
- 前端 `updateUserPwd` 改发 JSON body；`userInfo.vue` 手机/邮箱改为“有值才校验格式”，解决存量为空时无法保存的问题。

**验证**

- user1 `PUT /system/user/profile` JSON body 修改昵称/邮箱/手机 → `code=200`；GET 回读 `nickName=audit_profile_body`、`email=audit_profile@example.com`、`phonenumber=13800138000`，随后已恢复为 `演示用户1`。
- 存量 `sex=''` 用户可保存：user1 将 `sex` 提交为 `""` → `code=200`，回读 `sex=''`，随后恢复 `0`。
- 非法邮箱 body → 422 `Value error, 邮箱格式不正确`。
- `updatePwd` 旧密码错误 → `code=400`「旧密码错误」；新密码 `1` → 422 长度校验。
- 前端 `npm run build:prod` 通过（包含 userInfo 改动）。

### B. 英语学习：词书越权、导出过滤、due count

**修复**

- `english_practice.py` 新增 `_book_for_user`：只允许本人或系统预置词书。
- `new-words` / `mastery` / `submit_practice` 的 `bookId` 先校验归属。
- `due?bookId=` 的 `count` 与 `items` 共用同一个 `bookId` 条件。
- `words.py` 新增 `_allowed_book_ids`；`words/words/export` 与 `wordBooks/wordBooks/export` 只导出自己的 + 系统预置词书。

**验证**

- user2 访问 user1 词书 135：
  - `GET /words/practice/new-words?bookId=135` → `code=404`「词书不存在或无权查看」；
  - `GET /words/practice/mastery?bookId=135` → `code=404`；
  - `POST /words/practice/submit` body `bookId=135` → `code=404`「词书不存在或无权练习」；
  - `POST /words/words/export?bookId=135` → `code=404`。
- user2 `POST /wordBooks/wordBooks/export` 生成的 xlsx 只有表头、0 行（user2 没有自己的词书；不包含 user1 的 3 本词书）。
- user1 `GET /words/practice/due?bookId=128` → `count=0, returned=0`；`bookId=135` → `count=20, returned=5`，count 与 items 口径一致。

### C. 题库搭建：编辑加载/删题/保存保护

**修复**

- `create/index.vue` 新增 `editLoadError`；`loadEditData` 不再在请求前清空题目，失败时禁止保存。
- `handleSave` 的 `basicFormRef.validate()` 改为真正的 `try/catch return`，校验失败不再继续。
- 新增题干/选项非空校验；校验失败中止保存。
- `QuestionBuilder.vue` 的 `removeQuestion` 增加 `ElMessageBox.confirm`，取消不移除。
- 编辑保存：先更新/新增，全部完成后才删除被移除的旧题；读取原有题目失败直接中止；新建题库逐题写入失败时调用 `delQuestionBank` 清理空壳题库。
- `questions.py` 的 `update_question` 在题目标库/状态变化后重算 `total_questions`。

**验证**

- 前端 `npm run build:prod` 通过（含 `create/index.vue` 与 `QuestionBuilder.vue`）。
- 真实题库 1293 编辑页可加载题库名称与表单（页面显示 `14 / 50` 是名称字符计数，不是题目数；题目保存链路以 API/代码验证为主）。
- 后端 Python compile 通过。
- 真实临时题库/题目回归：创建 audit 题库 1308 → 加题后 `totalQuestions=1`；把题状态改 1 后 `totalQuestions=0`；恢复状态 0 后回到 1；删除题库 1308 成功（临时数据已清理）。
