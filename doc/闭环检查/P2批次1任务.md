## 验收项

### A. 题库练习

- [ ] 超过 2 小时的 ongoing 练习会话自动标记 `expired`
- [ ] 会话列表不长期堆积无意义 ongoing 记录
- [ ] 组合题/判断题数字答案服务端判分边界有真实测试

### B. 题库/后台

- [ ] 字典类型新增、修改、删除、详情、刷新缓存接口可用（不再落到 catch_all 假成功）
- [ ] 角色授权用户页面实际点按走通
- [ ] 后台监控/角色页面动态路由可进入

### C. 数据一致性

- [ ] 笔记点赞/取消点赞用原子 UPDATE，避免并发覆盖 `like_count`
- [ ] 删除题库/保存题库时题目关联数据清理由单一入口覆盖

### D. 消息/资料

- [ ] 消息中心红点聚合接口异常时不再拉全量列表做前端计数
- [ ] 我的资料同名上传、批量轮询、删除物理文件的边界在记录中明确

## 不伪装完成

- 定时任务/操作日志/登录日志：当前无数据表与后端实现，继续隐藏菜单，不创建假接口；
- 语义重排大模型：本批不做，低置信只做提示与单条结果；
- OCR 真实识别质量、1000 题性能、390px 全页面走查：列为未验证风险。
