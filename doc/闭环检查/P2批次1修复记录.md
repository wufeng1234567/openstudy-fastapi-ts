## 一、修复与验证

### A. 题库练习会话生命周期

**修复**

- `app/api/v1/practice.py` 新增 `_expire_stale_sessions()`：超过 2 小时仍为 `ongoing` 的练习会话标记为 `expired`。
- 开始练习、查询最近成绩两处入口都会触发清理，避免长期堆积无意义会话。
- 修复组合题判分时子题按 `sort_order,id` 排序；修复判断题 `1` 被误解析为“正确”而不是 0 基下标 `1` 的问题。

**验证**

- 插入 `create_time=now()-3h` 的 `audit_expire_session`，调用 `POST /questionPractice/session/start` 后 DB 状态变为 `expired`。
- 阅读组合题 id=168（5 个子题，含单选/判断/填空）全部答对时 `isCorrect=true`，子题结果逐项正确。
- 临时会话已删除。

### B. 字典类型 CRUD

**修复**

- `app/api/v1/system.py` 增加字典类型详情、新增、修改、删除、刷新缓存接口：
  - `GET /system/dict/type/{dict_id}`
  - `POST /system/dict/type`
  - `PUT /system/dict/type`
  - `DELETE /system/dict/type/{dict_id}`
  - `DELETE /system/dict/type/refreshCache`
- 新增 `app/models/dict.py` 的 `sys_dict_type` / `sys_dict_data` 表，字典类型和数据写入数据库；进程内 list/dict 只作为读缓存，刷新/重启后可重新加载。
- 删除类型时同步移除对应字典数据；删除字典数据只删字典配置，不再级联删除任何 `QuestionMain`；刷新接口不再落到 catch_all。

**验证**

- admin 新增 `audit_dict_test` → 详情 → 修改 → 刷新缓存（重载 DB）→ 删除，全部返回 200；删除后详情 404。
- 新增 `audit_dict_persist2` + 字典数据 → 刷新缓存 → 查询数据仍在 → 删除数据和类型成功；测试后 DB 中临时类型/数据均为 0。
- 当前字典类型列表 7 条，刷新接口 200。

### C. 点赞并发计数

**修复**

- `notes.py` 的点赞/取消点赞改为 `UPDATE note SET like_count = COALESCE(like_count,0) ± 1` 原子更新，避免并发读取旧值后覆盖计数。
- 保留重复点赞幂等返回。

**验证**

- user2 对 note 89 点赞：`likeCount 26→27`；重复点赞仍 200；取消后回 `26`，与基线一致。

### D. 消息中心兜底路径

**修复**

- `layout/front.vue` 的顶栏红点兜底从“拉全量 `listAll` 前端过滤 + 单独请求分享未读”改为一次 `unreadSummary()`，减少异常路径的 N+1/全量列表请求。
- 保留 `totalUnread` 主路径。

### E. 390px 窄屏练习布局

**修复**

- `openstudy-vue3-ts/src/assets/styles/PracticeComponent.css` 增加 `@media (max-width: 768px)`：
  - 题目区/答题卡从 75% + 25% 双栏改为单列；
  - 答题卡移到题目下方，宽度 100%；
  - 练习头、题目区和浏览模式卡片压缩内边距，避免横向溢出。

**验证**

- 390×844 headless Chrome 实测：修复前答题卡在右侧被截断；修复后题目区与答题卡纵向排列，页面无横向截断。

### F. 其他边界

- `question_payload` 补回 `status/createTime` 字段，避免练习脱敏接口复用到后台列表时缺字段。
- `saveWithQuestions` 删除题目时同步清理题目收藏、错题、斩题、笔记关联，避免孤儿行。
