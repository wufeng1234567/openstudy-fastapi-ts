# 演示需求与素材对照

| 编号 | 要展示的能力 | 画面应该看到什么 | 使用素材 / 入口 | 口播重点 |
|---|---|---|---|---|
| 01 | 资料入口不止文件上传 | 上传文档下拉：上传文档 / 粘贴文本 / 从网页导入 / 从题库导入 / 导入笔记 | 我的资料 → 上传文档下拉 | 各种来源都能进入同一个资料夹 |
| 02 | Word / PDF 导入 | 文件状态从待解析到可检索 | `01-高等数学-综合练习（第三章）.docx` / `.pdf` | 文档、公式、图片位置被保留 |
| 03 | Markdown / 文本导入 | 文档列表出现 Markdown 文档 | `02-微积分知识地图-演示.md` 或「粘贴文本」 | 不是只有 Word 才能进来 |
| 04 | 网页导入 | 输入 URL 或搜索词，结果显示网页来源 | `03-网页导入-示例链接.txt` | 网页也能成为知识资产 |
| 05 | 图片导入 | 图片出现在资料夹 / 画廊，能参与知识抽取 | `04-二重积分题截图.png` | 图片不是附件，是知识来源 |
| 06 | 图文混排题库 | 题干、公式、区域图同时显示 | 题库搭建 → AI 生成 → 上传 `.docx` 素材 → 导入题目 | 公式不丢、图片随题、题源可追 |
| 07 | 知识点关联 | 题目顶部出现知识点 chips，可筛选 | 第 1 题 → 知识点 `二重积分` / `偏导数与全微分` | 每道题知道考什么 |
| 08 | 知识百科 | 主题页有定义、要点、来源、相关主题 | 知识百科 → `偏导数` | LLM 把节点整理成可读页 |
| 09 | 知识图谱 | 选中节点、相邻关系、来源入口 | 知识图谱 → `偏导数` | 关系是真实的，不是装饰图 |
| 10 | 规划建议 | 阶段 / 天数 / 每天任务，能回原文和练习 | 知识详情 → 规划建议 | 计划来自资料和弱项，不是模板 |
| 11 | 一切皆对话 | 在智能对话里发出「看图谱 / 排计划」请求，出现工具调用与跳转 | 智能对话 | 对话可以进入系统任何位置 |
| 12 | AI+ Agent 能力 | Agent 理解意图、调用工具、返回回执 | 任一对话工具卡片 | OpenStudy 是 AI+ 应用，不是静态工具集合 |

## 录制时只选一条主线

建议只完整走 **01 → 02 → 06 → 07 → 08 → 09 → 10 → 11**。  
其余素材放在桌面，作为「我们支持这些来源」的补充，不逐项演示，避免 5 分钟超时。
