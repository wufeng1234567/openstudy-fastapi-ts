# OpenStudy 视频演示（约 5 分钟）

这个文件夹用于录制 OpenStudy 的项目演示视频，包含：

- `01-5分钟演示脚本.md`：逐段时间、操作、口播、预期画面、兜底方案
- `02-录制前检查清单.md`：开场前 5 分钟检查
- `03-演示需求与素材对照.md`：每个功能要展示什么、用哪个素材
- `04-智能体演示提示词.md`：可直接复制的智能体提示词
- `素材/`：可直接用于导入和演示的文件
- `参考画面/`：录制时可以对照的界面截图（不是 PPT 素材）

## 演示主线

> 一份考试周的高数 Word，先变成能刷的题；再从题目回到知识点、知识百科、原文；最后在智能对话里继续追问和生成下一步。

## 录制原则

- 只讲一条主线，不巡游所有功能；
- 每 30 秒至少让画面发生一次变化：状态变化、页面切换、题目出现、图谱展开、计划生成；
- 每段先给结果，再解释步骤；
- 遇到 AI 等待，不要停住不说话，按脚本里的兜底句继续讲；
- 不展示真实 token、密钥、内部调试数据。
